# Software Developer — Backend Focus

We are looking for a software developer to join our engineering team working on web applications, internal systems and APIs.

The role primarily involves backend development using Python and Django, with PostgreSQL used for data storage. Our applications expose REST APIs, integrate with external services and are deployed to Linux-based production environments.

The developer will work on existing systems as well as build new functionality. Typical work includes designing backend features, working with databases, debugging production problems, reviewing existing code and collaborating with other developers.

Candidates do not need experience with every technology in our stack. Strong experience with comparable technologies and evidence that the candidate can learn unfamiliar tools should also be considered.

## Core requirements

- Practical software development experience.
- Competence in at least one modern programming language.
- Experience building or maintaining backend applications.
- Understanding of databases and working with stored data.
- Ability to debug and solve technical problems.
- Understanding of APIs or communication between software systems.
- Ability to understand and modify existing code.
- Ability to explain technical work they have personally contributed to.

## Particularly relevant experience

Python, Django or comparable backend frameworks, PostgreSQL or other relational databases, REST APIs, Linux, Git, testing, deployment, production systems, performance optimisation and cloud infrastructure are all relevant. None should individually determine the outcome.
